# Overlays

Surfaces drawn above the page, each owning focus while it is open. They move focus in on open, trap it, and restore it on close.

## Components

- **ActionFailureDialog** — the report that an action already failed, with a retry.
- **ConfirmDialog** — the destructive-action confirmation.
- **ContextMenu** — the right-click menu.
- **Dialog** — the registry modal, portal, overlay and surface in one.
- **DialogSurface** — the dialog every settings dialog is built on, closed from the catalogue.
- **NoticeSurface** — the window's two-tier notice surface, transient and failure.
- **Popover** — an anchored, non-modal surface.
- **PopoverPanel** — the popover that can open on hover and wears the popup surface.
- **SearchPalette** — the search surface, its tabs, its results and its scope.
- **Tooltip** — the hover and focus hint.

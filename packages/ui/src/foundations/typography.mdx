# Typography

## Fonts

Two families, self-hosted through `@fontsource-variable/geist` and `@fontsource-variable/geist-mono`, imported at the top of `src/styles/globals.css`. They are bound in the `@theme inline` block: `font-sans` is the default everywhere. Every `h1` and `h2` renders in `font-heading` through a base style in `src/styles/globals.css`, so a Base UI Title part, which draws an `h2`, needs no class for it; `h3` to `h6` stay in `font-sans`. Inside the markdown typeset each level keeps its own family.

```css
--font-sans: "Geist Variable", sans-serif;
--font-heading: "Geist Mono Variable", monospace;
```

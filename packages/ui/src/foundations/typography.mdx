# Typography

## Fonts

One family, Geist Sans, self-hosted through `@fontsource-variable/geist` and imported at the top of `src/styles/globals.css`. It is bound in the `@theme inline` block: `font-sans` is the default everywhere, and `font-heading` resolves to the same stack, so the weight makes the heading. Every `h1` and `h2` renders in `font-heading` at `font-semibold` (600) through a base style in `src/styles/globals.css`, so a Base UI Title part, which draws an `h2`, needs no class for it unless a vendored primitive sets its own weight; `h3` to `h6` stay in `font-sans` at their own weight. Inside the markdown typeset each level keeps its own weight.

```css
--font-sans: "Geist Variable", sans-serif;
--font-heading: "Geist Variable", sans-serif;
```

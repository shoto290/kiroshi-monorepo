# Forms

What a reader fills in, plus the field furniture that labels and groups it. These are domain-free controls; the panels that assemble them into a real screen live under **Settings**.

## Components

- **Checkbox** — the registry boolean control.
- **RadioGroup** — the registry control for one choice out of a set.
- **Switch** — the on/off toggle.
- **ToggleSwitch** — the switch narrowed to a value, a handler and a label.
- **ProfilePictureField** — image upload with preview and removal.
- **SettingsField** — label, description and control on one row.
- **SettingsGroup** — a titled block of fields.
- **SettingsSelect** — the select bound to a settings row.
- **SettingsSwitch** — the switch bound to a settings row.
